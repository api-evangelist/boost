Boost is a distributed onchain incentives network that lets any team reward any onchain action with any token. Teams define target actions, fund a budget, and deploy campaigns across Base, Optimism, Arbitrum and other EVM chains, then measure ROI and iterate in real time. Boost ships two products — One-Time Actions and Time-Based Incentives (TBI) — plus RewardKit and a Headless SDK for embedding reward primitives, a public read-only Boost V2 REST API, a TypeScript SDK, a CLI, and a published MCP server. Founded by Ido Ben-Natan and Raz Niv and backed by Electric Capital and Greylock.

**Areas:** Company · Cryptocurrency · Web3 · Incentives · Rewards · Blockchain · DeFi · Onchain · EVM · Loyalty & Incentives

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Boost: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
